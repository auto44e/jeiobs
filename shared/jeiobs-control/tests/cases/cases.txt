# Black-box cases for jc-check (jeiobs-control, K1-PR1), run by run-cases.cmake. Expected values come
# from docs/jeiobs/tasks/006-control-protocols.md (K1 design, A1-A18) and the K1-PR1 contract with
# its addenda r1 and r2 (mapping schema v1, validation errors, compile checks 1-5, the jc-check CLI),
# not from the code. One command is not in the contract's CLI: value fromdouble (contract r2 item 1,
# see the value helpers).
#
# One case per line:   NAME | EXIT | EXPECTED | ARGS
#   NAME      letters, digits, ".", "_", "-". A name ending in "@posix" is skipped on Windows.
#   EXIT      expected exit code: 0 OK, 1 ERR, 2 usage. N,M accepts either (only where the contract
#             allows both readings). Whatever EXIT allows, an OK line needs exit 0 and an ERR line exit 1.
#   EXPECTED  compared with stdout after trailing CR and LF characters are removed:
#               TEXT          exact match, for example "OK" or "ERR E_DENIED r1"
#               ~REGEX        CMake regular expression that must match stdout (anchor it)
#               =FILE,...     stdout has exactly the bytes of FILE (without its trailing CR and LF):
#                             compact JSON with sorted keys. Several FILEs only where the contract
#                             allows more than one reading.
#               @FILE,...     stdout is one JSON object equal to FILE (member order and escapes free)
#               *             stdout is not checked
#             TEXT, ~REGEX and =FILE also need stdout to be one line: an ERR line comes alone.
#             An error code whose detail the contract leaves open is matched as "ERR E_CODE( .+)?".
#   ARGS      jc-check arguments, split on spaces and run from this directory. %XX is the byte 0xXX
#             (%20 space), the token "" is an empty argument and ${NAME} a value that run-cases.cmake
#             defines: ${WORK} is the scratch directory with the generated inputs, ${UTF8_PATH} a
#             mapping under a non-ASCII path and ${V_...} value JSON too long for one line here.
# Fields are separated by " | ". Blank lines and lines starting with # are ignored. Semicolons and
# backslashes are not allowed anywhere in this file (write %3B and %5C), square brackets are.
#
# Readings where the contract is open are stated in the section comments below.
