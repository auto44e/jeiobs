# Black-box cases for jw-check (jeiobs-workspace, S1-PR1 and S1-PR2), run by run-cases.cmake.
# Expected values come from docs/jeiobs/WORKSPACE_FORMAT.md and the S1-PR1 and S1-PR2 CLI contracts.
#
# One case per line:   NAME | EXIT | EXPECTED | ARGS
#   NAME      letters, digits, ".", "_", "-". A name ending in "@posix" is skipped on Windows
#             (an argument holds bytes that are not UTF-8, or names a POSIX device such as /dev/null).
#   EXIT      expected exit code: 0 OK, 1 ERR, 2 usage.
#   EXPECTED  compared with stdout after trailing CR and LF characters are removed:
#               TEXT     exact match, for example "OK readonly" or "ERR E_PATH dot"
#               ~REGEX   CMake regular expression that must match stdout (anchor it)
#               @FILE    stdout must be one JSON object equal to FILE (relative to this directory)
#               *        stdout is not checked
#             TEXT and ~REGEX also need stdout to be one line: an ERR line comes alone, without JSON.
#   ARGS      jw-check arguments, split on spaces and run from this directory.
#             %XX is the byte 0xXX (%20 space, %25 percent), the token "" is an empty argument,
#             ${WORK} is the scratch directory with the generated inputs, and ${P512}, ${P513},
#             ${C255}, ${C256}, ${C255U}, ${C256U} are generated paths (see run-cases.cmake).
# Fields are separated by " | ". Blank lines and lines starting with # are ignored.
# Semicolons, square brackets and backslashes are not allowed anywhere in this file
# (CMake list syntax). Write them as %3B, %5B, %5D and %5C.
#
# redact cases (ARGS start with "redact"): redact ROLE INFILE ${OUT} ${REPORT}, optionally followed
#   by --ws-placeholder P. ${OUT} and ${REPORT} are this case's OUTFILE and REPORT in the scratch
#   directory. The runner deletes them before the case runs. EXPECTED is the stdout check above,
#   followed for a case that prints OK by
#     report=FILE,FILE,...   REPORT must be one JSON object equal to one of the FILEs (several FILEs
#                            only where the contract allows more than one reading), or report=* for
#                            "not compared"
#     out=FILE               (optional) OUTFILE must have exactly the bytes of FILE
#   and the runner then checks, for every redact case:
#     - OUTFILE exists if and only if REPORT says "outcome":"stored", and never after an ERR line.
#     - Each redaction has a string pointer, a known kind, integers 0 <= start <= end <= INFILE size,
#       "was": false if forced, and the redactions are sorted by start and do not overlap.
#     - OUTFILE is INFILE with exactly the reported ranges replaced, by "" (stream_key,
#       bearer_token, rtmp_auth, oauth_token, url_credential), "true" (forced) or the placeholder
#       (ws_password). Every other byte is unchanged.
#     - OUTFILE holds no "SECRETvalue" (each fixture secret starts with it) and as many "PLAINvalue"
#       as INFILE (values the rules must keep, often next to a secret).
#     - Without --ws-placeholder, each placeholder is 32 characters of A-Z, a-z, 0-9, and a second
#       run gives the same REPORT and another placeholder.
