# Black-box cases for jw-check (jeiobs-workspace, S1-PR1 to S1-PR3), run by run-cases.cmake.
# Expected values come from docs/jeiobs/WORKSPACE_FORMAT.md and the S1-PR1, S1-PR2 and S1-PR3 CLI contracts.
#
# One case per line:   NAME | EXIT | EXPECTED | ARGS
#   NAME      letters, digits, ".", "_", "-". A name ending in "@posix" is skipped on Windows
#             (an argument holds bytes that are not UTF-8, or names a POSIX device such as /dev/null).
#   EXIT      expected exit code: 0 OK, 1 ERR, 2 usage. N,M accepts either (only where the contract
#             allows both readings). Whatever EXIT allows, an OK line needs exit 0 and an ERR line exit 1.
#   EXPECTED  compared with stdout after trailing CR and LF characters are removed:
#               TEXT     exact match, for example "OK readonly" or "ERR E_PATH dot"
#               ~REGEX   CMake regular expression that must match stdout (anchor it)
#               @FILE    stdout must be one JSON object equal to FILE (relative to this directory)
#               *        stdout is not checked
#             TEXT and ~REGEX also need stdout to be one line: an ERR line comes alone, without JSON.
#   ARGS      jw-check arguments, split on spaces and run from this directory.
#             %XX is the byte 0xXX (%20 space, %25 percent), the token "" is an empty argument,
#             ${WORK} is the scratch directory with the generated inputs, and ${P512}, ${P513},
#             ${C255}, ${C256}, ${C255U}, ${C256U} are generated paths (see run-cases.cmake).
# Fields are separated by " | ". Blank lines and lines starting with # are ignored.
# Semicolons, square brackets and backslashes are not allowed anywhere in this file
# (CMake list syntax). Write them as %3B, %5B, %5D and %5C.
#
# redact cases (ARGS start with "redact"): redact ROLE INFILE ${OUT} ${REPORT}, optionally followed
#   by --ws-placeholder P. ${OUT} and ${REPORT} are this case's OUTFILE and REPORT in the scratch
#   directory. The runner deletes them before the case runs. EXPECTED is the stdout check above,
#   followed for a case that prints OK by
#     report=FILE,FILE,...   REPORT must be one JSON object equal to one of the FILEs (several FILEs
#                            only where the contract allows more than one reading), or report=* for
#                            "not compared"
#     out=FILE               (optional) OUTFILE must have exactly the bytes of FILE
#     timeout=N              (optional) the case fails after N seconds (default 120)
#   FILE is relative to this directory, or ${WORK}/... for a file that run-cases.cmake generates.
#   and the runner then checks, for every redact case:
#     - OUTFILE exists if and only if REPORT says "outcome":"stored", and never after an ERR line.
#     - Each redaction has a string pointer, a known kind, integers 0 <= start <= end <= INFILE size,
#       "was": false if forced, and the redactions are sorted by start and do not overlap.
#     - OUTFILE is INFILE with exactly the reported ranges replaced, by "" (stream_key,
#       bearer_token, rtmp_auth, oauth_token, url_credential), "true" (forced) or the placeholder
#       (ws_password). Every other byte is unchanged.
#     - OUTFILE holds no "SECRETvalue" (each fixture secret starts with it) and as many "PLAINvalue"
#       as INFILE (values the rules must keep, often next to a secret), also over 4 MiB.
#     - A REPORT with more than 256 ranges is checked by its equality with the expected REPORT and
#       out=FILE (made together by run-cases.cmake) instead of range by range.
#     - Without --ws-placeholder, each placeholder is 32 characters of A-Z, a-z, 0-9, and a second
#       run gives the same REPORT and another placeholder.
#
# plan cases (ARGS start with "plan"): plan TREE_DIR, then any of --roots F, --parent F, --uid-seed N
#   and --app-dir D. EXPECTED may start with these tokens:
#     tree=NAME     run-cases.cmake builds fixtures/plan/trees/NAME.tree into ${WORK}/plan/NAME (from
#                   scratch, once per run), which ${TREE} names
#     uids=random   (with @FILE) every uid is a distinct lowercase UUIDv4. Each is replaced, collections
#                   first, by uid-random-0001, uid-random-0002, ... before the comparison, and a second run
#                   must give other uids
#     timeout=N     the case fails after N seconds (default 120)
#   followed by TEXT, ~REGEX or * as above, or by
#     @FILE,FILE,...  stdout is one JSON object equal to one of the FILEs (several only where the contract
#                     allows more than one reading), both in canonical form: inside each run of consecutive
#                     stored entries of one profile, of one collection or of the module configs (role
#                     module.*) the entries are sorted by path, then ids are renumbered and every bak
#                     follows its entry. A profiles dir "basic/profiles/<d>" counts as "<d>", and warnings
#                     are sorted. Before that, the ids of stdout must be e1, e2, ... in entry order and
#                     every bak must name an entry. FILE is relative to this directory, or ${WORK}/... for
#                     a file run-cases.cmake generates. The string "<any>" in a FILE stands for any value
#                     (only where the contract leaves a value open)
#     entries=N       stdout is one JSON object with N entries (an output too big to compare)
#   A tree file has one item per line, blank lines and # comments aside. PATH is relative to the tree, %XX
#   is the byte 0xXX and {N*C} the character C repeated N times. No semicolon, square bracket or backslash
#   (use %XX).
#     needs F ...         the tree needs symlinks, case-sensitive, non-utf8-names, reserved-names,
#                         long-names or unreadable-dirs. Where the filesystem lacks one (probed in
#                         ${WORK}/plan-probe), its cases are skipped. unreadable-dirs is missing on Windows
#                         and for root, who can list any directory
#     dir PATH            a directory
#     file PATH SIZE      a file of SIZE bytes "x", every byte of its name kept, backslashes included
#     copy PATH FILE      a copy of FILE (relative to this directory, or ${WORK}/... for a generated file)
#     hardlink PATH FILE  a hard link to FILE (as for copy), or a copy where hard links fail
#     link PATH TARGET    a symbolic link to TARGET (relative to the link's directory)
#     many DIR N PREFIX   N files DIR/PREFIX0001.txt, ..., where file k has k bytes
#     profiles DIR N M    N folders DIR/p000, ..., each with basic.ini and M files u001.txt, ... of 1 byte
#     unreadable PATH     the directory PATH (made by an earlier line) has only the owner's write right
#                         while each case of the tree runs, so it cannot be listed or entered, and 0755
#                         between cases
